# 和 iOS 原生键盘的差异：暂缓项

状态：**暂不处理**（2026-11-10 记录）。用到时再讨论、再优化。

已经对齐 iOS 的部分（同一天完成）：数字、符号页跟随中英文出中英文标点；空格左右拖动移光标；
双击 Shift 锁定大写；长按退格加速、之后整词删除。按键振动默认关闭，在 `•••` 菜单里开关。

## 1. 字母键的角标和长按

- **iOS**：键帽上只有字母，没有角标；长按字母弹出带音标的字母（é、è、ê…）。
- **现在**：长按输出符号、第一排上滑输出数字，键帽右上角有提示小字。
- **现状判断**：目前用不到 iOS 的音标字母，保留现在的符号手势。
- **如果以后要改**：在 `ios.trime.yaml` 的字母键上把 `long_click` 换成 `popup` 列表（Trime 支持长按弹出多个候选键），
  再给字母键设 `label_symbol: ' '` 隐藏角标。

## 2. 双击空格输入句号

- **iOS**：快速双击空格输入「。」（英文是「. 」）。
- **现状判断**：不需要，空格保持原来的功能。
- **如果以后要改**：空格键本来就能识别双击（`double_click` 行为），需要在
  `ios_space` 上配 `double_click`，并处理「先删掉刚上屏的空格再出句号」，要改一点代码。
  要注意不能影响虎码、双拼里空格上屏首选的手感。

## 3. 数字页上打数字时会选中候选

- **现象**：有未上屏的编码时，在数字页按数字键，会选中对应序号的候选，而不是输入数字。
- **现状判断**：不需要处理。
- **如果以后要改**：数字页的数字键改成直接上屏（和中文标点一样用 `commit` 预设键，
  会先上屏首选再上屏数字），或者有编码时数字先上屏编码。

## 4. 按键放大气泡

- **iOS**：按下字母时，按键往上长出一个和按键连成一体的放大字母（上宽下窄的形状）。
- **现在**：在代码里整体关闭（`KeyView.kt` 的 `KEY_PREVIEW_ENABLED = false`），不受「按键弹出预览」设置影响。
  之前打开时是一个白色圆角矩形，和 iOS 的效果差很多，用户觉得太丑。
  只改设置默认值关不掉：设置页会把旧版的默认值「开」存进去。
- **已经做的**：主题里补上了 `style/popup_*` 尺寸和颜色（之前是 0，完全看不见），功能键不弹气泡。
- **如果以后要改**：需要自己画 iOS 那种按键和气泡连成一体的形状（自定义 Drawable 或 Path），
  字母放在上半部分，还要处理最左、最右一列气泡不能超出屏幕。代码在 `ime/popup/PopupEntryUi.kt`、
  `PopupDelegate.kt`。

## 其他已知的小差异（顺手记下）

- 空格拖动移光标不需要先长按（iOS 要先长按空格），横向一划就开始移动。
